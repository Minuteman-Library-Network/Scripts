A pair of scripts used to generate a monthly reports for Wayland, run as a single task.

**Wayland Monthly Circ Value**
Report on the cost per circ in the past month broken out by item type

**Wayland Monthly Patrons By Checkout Location**
Report on the number of unique patrons and average checkout per patrons by service location

Execution Plan:
* Run query to generate data
* Compile query results into an Excel (Wayland Monthly Circ Value) or CSV (Wayland Monthly Patrons By Checkout Location) File
* Email file to designated staff members as an attachment
